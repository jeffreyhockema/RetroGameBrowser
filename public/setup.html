3 Signing in

Accounts keep each person's favorites apart, and let you choose who may play from outside your home. You get an admin page to manage them. Pick one, both or neither.

How to get a client ID
  1. Open Google Cloud Console and create a project (any name).
  2. APIs & Services → OAuth consent screen: choose External, fill in an app name and your email, and save. Leave it in Testing and add the Google accounts that will sign in as test users, or publish it (it only asks for name, email and picture, which needs no review).
  3. APIs & Services → Credentials → Create credentials → OAuth client ID, type Web application. Under Authorized JavaScript origins add . No redirect URIs are needed.
  4. Copy the Client ID (not the secret, which isn't used) into the box above.
